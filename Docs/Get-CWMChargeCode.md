# Get-CWMChargeCode

## SYNOPSIS
Gets the charge codes.

## SYNTAX

```
Get-CWMChargeCode [<CommonParameters>]
```

## DESCRIPTION
Returns the rows of the ChargeCode report.
Calls Get-CWMReport, which calls GET
/system/reports/ChargeCode.

## EXAMPLES

### EXAMPLE 1
```
Get-CWMChargeCode
```

Returns every charge code as an object.
