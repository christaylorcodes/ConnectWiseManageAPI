# Get-CWMSalesActivity

## SYNOPSIS
Gets sales activities.

## SYNTAX

```
Get-CWMSalesActivity [[-id] <Int32>] [-count] [[-condition] <String>] [[-orderBy] <String>]
 [[-childConditions] <String>] [[-customFieldConditions] <String>] [[-page] <Int32>] [[-pageSize] <Int32>]
 [[-fields] <String[]>] [-all] [<CommonParameters>]
```

## DESCRIPTION
Retrieves the sales activities from ConnectWise Manage, or a single sales activity by id.
Calls GET
/sales/activities; -id adds /{id} and -count adds /count.

## EXAMPLES

### EXAMPLE 1
```
Get-CWMSalesActivity -condition "name contains 'Support'" -all
```

Retrieves the sales activities that match the condition.

### EXAMPLE 2
```
Get-CWMSalesActivity -id 5
```

Retrieves sales activity 5.
